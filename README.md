# Stock Price Prediction using Machine Learning 📈

This project predicts the future stock prices of Apple Inc. (AAPL) using historical data and Linear Regression.

## 🚀 Overview
- **Data Source:** Yahoo Finance (yfinance)
- **Algorithm:** Linear Regression (Scikit-Learn)
- **Goal:** Predict the next day's closing price based on past trends.

## 🛠️ Tech Stack
- Python
- Pandas & Numpy (Data Manipulation)
- Matplotlib (Visualization)
- Scikit-Learn (Machine Learning)

## 📊 Results
The model successfully predicts trends with a high degree of correlation between actual and predicted prices.

## 📂 Project Structure
- `stock_prediction.ipynb`: The main Jupyter notebook with code and analysis.
- `README.md`: Project documentation.
